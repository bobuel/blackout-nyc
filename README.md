# Blackout NYC

[Play in your browser](https://bobuel.github.io/blackout-nyc/)

Six survivors. Seven neighborhoods. One way home during New York's 1977 blackout. Explore in real time and resolve confrontations with positional tactics on the same street.

**Browser development build 0.3.0-web4. For mature audiences; not formally rated.** Contains violence, strong language, sexual themes, sex work, drugs, alcohol, coercion and exploitation.

Use a desktop browser with hardware acceleration and a keyboard/mouse. Click Play, then Choose a Survivor. WASD moves, E interacts, Shift moves cautiously, Tab inspects, and Escape pauses. Settings includes fullscreen, graphics, audio and controls. Reading and planning do not spend campaign time.

Saves stay in this browser on this device. Clearing site data or using private browsing may erase them. The first street can pause while the browser compiles 3D graphics. The game download is approximately 114 MB before HTTP compression; the content pack itself is 74 MB.

This repository hosts the exported Godot game, like [Brassline](https://bobuel.github.io/brassline/). GitHub Pages serves the root of `main`. It has no runtime server, accounts or AI service. Browser graphics use WebGL 2 with 1024-pixel texture limits; the original Windows build remains separate.

See [credits](CREDITS.md), [asset notices](asset-notices/), and [build hashes](BUILD.json). This is a playable development campaign, not a final-quality release. Native full-campaign checks and bounded browser checks do not establish full browser-campaign acceptance or player enjoyment.
